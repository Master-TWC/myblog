# Python 实验：统计「十五五」规划报告热词频率（词云）

> 实验要求：统计"十五五"规划报告的热词频率并出词云。
> 这一篇想说的不是"怎么画词云"（代码 20 行就够了），而是——
> **词云好不好看，90% 取决于停用词表，而不是配色和形状**。

## 一、语料：先拿到干净的原文

来源是新华社受权发布的《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》，官网原文页：

```
https://www.gov.cn/zhengce/202510/content_7046050.htm
```

保存为 txt 后先做两件小事：

```python
text = Path("data/十五五规划建议.txt").read_text(encoding="utf-8")
text = re.sub(r"\n{2,}", "\n", text)          # 合并空行
text = re.sub(r"[一二三四五六七八九十]+、", "", text)   # 去掉章节编号
```

去编号后 **20,412 字、117 行、15 章**（对应"十五五"的十五个部分）。

## 二、分词：jieba 之后必须过三层筛

```python
words = [w for w in jieba.cut(text) if len(w) >= 2 and _is_cjk(w)]
```

只有这一层的话，Top 词是"发展 建设 推进 加快 加强"——**全是公文动词，看不出任何信息**。

所以加三层过滤：

| 层 | 过滤内容 | 理由 |
| --- | --- | --- |
| 1 | 长度 < 2、非中文字符 | 去掉标点、数字、单字 |
| 2 | 通用停用词（的/了/是/和…） | 语法词无信息量 |
| 3 | **公文大词**（发展/建设/推进/加快/加强/工作/要求…） | 体裁决定的"高频噪声" |

第三层是这次实验的关键判断：

> 「发展」在全文出现 **189 次**，「建设」133 次、「推进」107 次、「加强」100 次——但它们对读者没有区分度：**每一章都在发展**。
> 把体裁词滤掉之后，浮现出来的才是内容词：经济（48）、治理（44）、战略（41）、科技（37）、产业（36）。

## 四、分章节统计：同一份文件，十五种重点

把 15 章拆开各自统计，能看出每一部分的"用力点"：

| 三、建设现代化产业体系 | 产业 13、服务业 8、基础设施 7 |

整体热词是"经济/治理/战略"，但拆到章节就成了"投资/消费""就业/教育""绿色/能源"——**全局词频会抹平局部重点，分章统计才看得见结构**。

## 五、词云参数里的几个小决定

```python
WordCloud(
    font_path="C:/Windows/Fonts/msyh.ttc",   # 中文字体必须显式指定
    width=1600, height=1000,
    background_color="white",
    max_words=180,
    colormap="viridis",
    random_state=42,                          # 固定布局，方便复现
).generate_from_frequencies(counter)
```

- **必须指定中文字体**，否则中文全是方框（`msyh.ttc` 微软雅黑）；
- `random_state` 固定后，每次布局一致，改动才可比较；
- `max_words=180` 是权衡：词太多会挤成噪点，词太少看不出分布；
- 用 `generate_from_frequencies` 而不是 `generate(text)`，因为**词频已经统计过了，不该让 wordcloud 再分一次词**。

## 七、小结

1. **停用词表是词云质量的第一决定因素**：不滤公文大词，出来的图全是"发展建设推进"；
2. **词云负责"第一眼"，条形图负责"读数"**，两个一起放才不容易被误读；
3. **全局统计 + 分章统计** 是读政策文本的基本套路，缺了后者会漏掉真实重点；
4. 中文字体、`random_state`、`generate_from_frequencies` 是复现性的三个开关，一开始就设好能省很多事。
