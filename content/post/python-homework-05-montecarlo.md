# Python 实验：蒙特卡洛方法手搓图形

> 蒙特卡洛就一句话：**用大量随机试验，去逼近一个确定但算不动的数**。
> 这次做了四个经典实验，全部手写循环（不调任何统计库），并记录真实误差——
> 因为蒙特卡洛最有意思的地方，恰恰是"它总是错一点"。

## 一、四个实验的设计

| # | 实验 | 随机源 | 目标量 | 期望误差量级 |
| --- | --- | --- | --- | --- |
| 1 | 撒点估 π | 单位正方形内均匀点 | π | 1/√n |
| 2 | 收敛曲线 | 复用第 1 次撒点 | 看误差怎么降 | — |
| 3 | 蒲丰投针 | 针的位置与角度 | π | 更慢 |
| 4 | 随机游走 | 每步方向 | 终点距离 ≈ √n | 单次波动极大 |
| 5 | 定积分 | 曲线上下方撒点 | ∫[0,1] x²dx = 1/3 | 1/√n |

## 二、撒点算 π：最简单也最直观

正方形里均匀撒点，落在内切圆里的比例 ≈ 圆面积/正方形面积 = π/4：

```python
n = 200_000
points = rng.random((n, 2)) * 2 - 1                # [-1, 1)²
inside = (points ** 2).sum(axis=1) <= 1
pi_est = 4 * inside.sum() / n
```

实测：**π ≈ 3.13834，绝对误差 0.00325**（20 万次）。

## 三、收敛曲线：误差按 1/√n 掉

一次撒 10 万个点，然后**按前缀**统计 n=100、300、1000 … 10 万时的估计值：

```
100→3.2000  300→3.0667  1,000→3.0320  3,000→3.1333
10,000→3.1404  30,000→3.1567  100,000→3.1400
n=100,000 时相对误差 0.0520%
```

数值忽高忽低是正常的——**单次估计不是单调收敛的**，只有"误差的量级"符合 1/√n：想让误差再小 10 倍，就得撒 100 倍的点。这条规律决定了蒙特卡洛"能用但不精确"的定位。

## 四、蒲丰投针：最反直觉的一个

一根长度 L=1 的针随机落到间距 d=1 的平行线上，能相交的概率是 `2L/(πd) = 2/π`，于是 `π ≈ 2n/命中次数`。

关键是**随机量怎么取**：针中心到最近线的距离 y，其分布是 `U(0, d/2)`，不是 `U(0, d)`。

```python
def buffon(n=20_000, L=1.0, d=1.0):
    theta = rng.uniform(0, np.pi / 2, n)     # 针与线的夹角
    y = rng.uniform(0, d / 2, n)             # 中心到最近线：0 ~ d/2
    hits = (y <= (L / 2) * np.sin(theta)).sum()
    return 2 * n / hits
```

> 第一版写成 `y = uniform(0, 1)`，得到 P = 1/π，估计值 **6.2588**——差了整整一倍。
> 推公式只花两分钟，检查"随机变量定义域"花了我二十分钟。**蒙特卡洛的 bug 几乎都出在这里。**

改对后：**π ≈ 3.16256，误差 0.02096**（2 万次投针），比撒点法差一个数量级——这也是教科书说"蒲丰投针不适合实际计算"的原因。

*命中（红）与未命中（蓝）的针，命中比例就是 π 的倒数关系*

## 五、随机游走：终点距离 ≈ √n

```python
steps = 5_000
for _ in range(3):
    angles = rng.uniform(0, 2 * np.pi, steps)
    xs = np.cos(angles).cumsum()
    ys = np.sin(angles).cumsum()
    final = math.hypot(xs[-1], ys[-1])
```

实测三次终点距离：**52.1、42.1、93.4**，理论值 √5000 ≈ 70.7。

单次相差两倍很正常——终点距离本身是随机变量，**要验证 √n 规律，得跑几百次取平均**。这一条在图上看得最清楚：有的路径潇洒走远，有的原地打转。

## 六、定积分：把面积比变成积分值

在 1×1 方格撒点，落在曲线 `y=x²` 下方的比例就是积分值：

```python
n = 200_000
x, y = rng.random(n), rng.random(n)
integral = (y <= x ** 2).mean()
```

实测：**0.33289，误差 0.000438**——比估 π 还准，因为被积函数简单、方差小。

## 八、小结

1. **误差按 1/√n 下降**：想准 10 倍，得撒 100 倍的点——这是蒙特卡洛的天花板，也是它只用在"高维/无解析解"场景的原因；
2. **随机变量的定义域比公式重要**：蒲丰投针写错 y 的范围，结果直接翻倍；
3. **单次结果没有意义**：随机游走要跑多次看分布，收敛曲线要看趋势而不是某一点；
4. 蒙特卡洛的优势是**维度无关**——积分从 1 维到 10 维，代码一行不改，误差量级不变，这是数值积分做不到的。
